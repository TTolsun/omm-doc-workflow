# 컴포넌트 이름

**이 컴포넌트를 수정하기 전에 확인할 계약을 한 문장으로 설명합니다.** 실제 코드의 이름과 역할을 사용합니다.

## 시스템 안에서의 위치

입력·처리·출력과 호출 주체를 구조도로 연결합니다. 실제 코드로 확인한 엣지만 표시하고, 조건부 경로에는 조건을 적습니다. 코드 파일은 해당 프로젝트 바인딩의 근거에 추가합니다.

## 역할과 소유권

| 항목 | 작성할 내용 |
| --- | --- |
| 역할 | 컴포넌트가 담당하는 처리와 범위를 설명합니다. |
| 소유권 | 버퍼·요청·콜백을 누가 만들고 인계받고 해제하는지 설명합니다. |
| 실행 조건 | 활성화 조건과 실패·종료 조건을 설명합니다. |

## 주요 실행 흐름

진입점부터 결과 반환까지 단계별로 설명합니다. 실행 경로 수는 명시적으로 세어 확인한 경우에만 표시합니다.

## 의존 관계

입력과 출력, 호출 방향을 구분합니다. 코드 의존성과 설계 문서가 설명하는 의도를 서로 다른 근거로 표시합니다.

## 코드 근거

코드 파일·심볼과 검토 커밋을 연결합니다. 화면의 근거 패널은 바인딩·원고 인용·검토 기록에서 생성하며 수치를 직접 적지 않습니다.

## 변경 이력

코드로 확인한 변경과 CSWPR·설계 결정의 출처를 연결합니다. 일반 코드 변경을 검증 없이 아키텍처 변경으로 분류하지 않습니다. 기록이 없으면 해당 사실을 적거나 이 절을 생략합니다.

다음으로 이 컴포넌트의 출력이나 소유권을 인계받는 컴포넌트 문서 하나를 연결합니다.
